# Furniture sound effects

All six clips below are from Kenney's **Interface Sounds** pack, version 1.0.
They were downloaded from <https://kenney.nl/assets/interface-sounds>. The pack's
included `Kenney-License.txt` states that the sounds are licensed under
Creative Commons Zero (CC0) and may be used in personal, educational, and
commercial projects. Kenney's licensing FAQ confirms CC0/public-domain use:
<https://kenney.nl/support>. Attribution is not required.

| File in this folder | Original pack file | Use |
|---|---|---|
| `click_001.ogg` | `click_001.ogg` | Furniture selection |
| `back_001.ogg` | `back_001.ogg` | Furniture deselection |
| `select_001.ogg` | `select_001.ogg` | Movement start |
| `confirmation_001.ogg` | `confirmation_001.ogg` | Optional movement stop (off by default) |
| `close_001.ogg` | `close_001.ogg` | Furniture deletion |
| `drop_001.ogg` | `drop_001.ogg` | Wall impact |

`AudioManager.prefab` references these project copies. The undocumented
`Assets/DormVRScenes/Resources/soundshelfstudio-ui-click-deep-512211.mp3`
is intentionally left untouched and unused until its source/license can be
verified.
